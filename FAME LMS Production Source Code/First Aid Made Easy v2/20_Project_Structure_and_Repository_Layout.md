## 4. Configuration Files

### 4.1 turbo.json

```json
{
  "$schema": "https://turbo.build/schema.json",
  "globalDependencies": [".env"],
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": [".next/**", "!.next/cache/**"]
    },
    "lint": {},
    "test": {
      "dependsOn": ["build"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    }
  }
}
```

### 4.2 pnpm-workspace.yaml

```yaml
packages:
  - "packages/*"
```

---

*This structure separates concerns cleanly: frontend and backend are independent build units, modules encapsulate vertical feature slices, and shared code lives in dedicated packages. The monorepo enables atomic commits spanning frontend + backend while keeping each deployable unit independent.*
